# 🚀 Quick Start Deployment

Get your app live in 30 minutes (after account setup).

## ⚡ Super Fast Track

### 1. Prerequisites (5 min)

\`\`\`bash
# Install EAS CLI
npm install -g eas-cli

# Login to Expo
eas login

# Navigate to app
cd mobile-app
\`\`\`

### 2. Configure (2 min)

\`\`\`bash
# Initialize EAS
eas build:configure

# Update app.json with your bundle IDs
# iOS: com.yourcompany.newfamilytree
# Android: com.yourcompany.newfamilytree
\`\`\`

### 3. Build (20 min wait time)

\`\`\`bash
# Build for both platforms
npm run build:all

# Or individually:
npm run build:ios    # iOS only
npm run build:android # Android only
\`\`\`

### 4. Submit (3 min)

\`\`\`bash
# Submit to both stores
npm run submit:all

# Or individually:
npm run submit:ios
npm run submit:android
\`\`\`

## 📱 Store Review Times

- **iOS**: 24-48 hours
- **Android**: 1-7 days (avg 2-3 days)

## ✅ Before You Start

- [ ] Apple Developer Account ($99/year)
- [ ] Google Play Developer Account ($25 one-time)
- [ ] App icon ready (1024x1024, no transparency)
- [ ] Screenshots prepared (at least 3 per platform)
- [ ] Privacy policy URL live
