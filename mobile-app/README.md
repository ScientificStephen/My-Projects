# New Family Tree Mobile App

A React Native mobile application for building and nurturing chosen families.

## Features

- 📱 Native iOS and Android support
- 🎨 Beautiful luxury design with gold accents
- 👨‍👩‍👧‍👦 Family tree visualization
- 📝 Share family stories and memories
- 📸 Photo uploads and memory gallery
- 🔐 Authentication with Google and Facebook
- 💬 Social sharing capabilities

## Getting Started

### Prerequisites

- Node.js 18+
- Expo CLI
- iOS Simulator (Mac) or Android Studio

### Installation

\`\`\`bash
cd mobile-app
npm install
\`\`\`

### Running the App

\`\`\`bash
# Start Expo
npm start

# Run on iOS
npm run ios

# Run on Android
npm run android
\`\`\`

## Tech Stack

- React Native
- Expo
- React Navigation
- Supabase (Backend)
- React Native Linear Gradient
- Lucide React Native (Icons)
